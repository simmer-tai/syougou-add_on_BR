# 称号アドオン (Title Add-on)

プレイヤーの様々な行動を記録し、実績に応じた「称号」を獲得できるアドオンです。
獲得した称号はネームタグに表示し、他のプレイヤーに自慢することができます。

## 📥 導入方法
1. ビヘイビアーパックとリソースパックをワールドに適用してください。
2. ワールド設定で「ベータAPI (Beta APIs)」を有効にする必要はありません（安定版APIを使用しています）。
   ※ただし、スクリプトが動作する環境が必要です（Minecraft 1.21.0以上推奨）。

## 🎮 使い方

### メニューを開く
メニューを開くには、以下の2つの方法があります。

1.  **「称号メニュー」アイテムを使用する**:
    ゲーム参加時に配布される「称号メニュー」本（黄色い名前のアイテム）を長押し（右クリック）して使用します。

2.  **チャットコマンド**:
    アイテムがない場合や、手動で開きたい場合は以下のコマンドを入力します。
    `/scriptevent syougou:open`

### メニューの機能
*   **カテゴリ選択**: 獲得済みの称号があるレアリティが表示されます。
*   **称号の装着**: 好きな称号を選ぶと、ネームタグ（頭上の名前）に称号が表示されます。
*   **トラッカー設定**: 称号の下に「総ブロック破壊数」や「モブ討伐数」などの統計情報を表示できます。
*   **称号を外す**: 「称号を外す」ボタンで元の名前に戻せます。
*   **統計データ**: 現在の自分の実績データ（破壊数や移動距離など）を確認できます。

## 📊 トラッカー機能
称号の下に追加で統計情報を表示できる「トラッカー」機能があります。
メニューの「トラッカーを変更」から表示したい情報を選択できます。

**表示可能な項目:**
*   **なし**: 表示しません（デフォルト）
*   **総ブロック破壊数**: これまでに破壊したブロックの総数
*   **移動ブロック数 (X,Z)**: X軸とZ軸（平面）の移動距離
*   **総モブ殺害数**: 倒したモブの総数
*   **作物収穫回数**: 収穫した作物の数
*   **ダイアモンド鉱石破壊数**: ダイヤモンド鉱石の破壊数（シルクタッチ有無問わず）

## 🏆 称号システム

### 管理者向けコマンド
チャット欄で以下のコマンドを入力すると、スキルレベルを自由に設定できるチートUIが開きます。
**※このコマンドはタグ「admin」を持つプレイヤーのみ使用できます。**
（使用前に `/tag @s add admin` を実行して権限を付与してください）

`/scriptevent syougou:cheat`

条件を達成すると、チャット通知と効果音でお知らせします。一度獲得した称号は永続的に保存されます。

### レアリティと色
*   **レザー** (茶色): 初心者向け

## 📈 スキルシステム
プレイヤーの行動によって各分野のスキルレベルが上昇し、様々な恩恵を受けられます。
レベルアップに必要な経験値は、レベルが上がるごとに少しずつ増えていきます。

| スキル名 | アイコン | バフ効果 (パッシブ) | 経験値の獲得条件 |
| :--- | :---: | :--- | :--- |
| **マスタリー** | 👑 | 特になし（称号獲得のみ） | 他のスキルレベルが1上がるごとに +10 XP |
| **採掘 (Mining)** | ⛏️ | 鉱石採掘時、追加で鉱石がドロップする確率が増加 <br> (Lv * 0.5%) | 天然の鉱石や石を採掘 |
| **農業 (Farming)** | 🌾 | 作物収穫時、追加で作物がドロップする確率が増加 <br> (Lv * 0.1%) | 作物を収穫 <br> (カボチャ・スイカのシルクタッチ回収は対象外) |
| **林業 (Forestry)** | 🪓 | 原木破壊時、追加で原木がドロップする確率が増加 <br> (Lv * 0.5%) | 天然の原木を伐採 (+5 XP) |
| **畜産 (Husbandry)** | 🐾 | 1. 羊の毛刈り時、追加で羊毛ドロップ (Lv * 0.3%) <br> 2. 餌やり時、確率で餌を消費しない (Lv * 0.5%, 最大50%) <br> 3. **[Lv25~]** 周囲のペット・動物に再生能力Ⅰを付与 | 羊の毛刈り (+5 XP) <br> 動物への餌やり (+5 XP) <br> 動物の手懐け (+20 XP) <br> 動物・家畜の屠殺 (+10 XP) |
| **狩人 (Hunter)** | ⚔️ | 1. 敵モブが追加アイテムをドロップ (Lv * 0.3%) <br> 2. 敵モブ討伐時、経験値が倍になる確率 (Lv * 0.3%) | 敵モブを倒す: <br> ・オーバーワールド (+10 XP) <br> ・ネザー (+20 XP) <br> ・エンド (+30 XP) |

## 📊 統計データ
メニューの「統計データを確認」から以下の項目が見れます。
*   総ブロック破壊数 / 設置数
*   モブ討伐数
*   移動距離（地上 / 水中）
*   死亡回数
*   生存日数
*   食べた食料の種類数
*   特定の鉱石採掘数

## ⚠️ 注意事項
*   サバイバルモードでの動作を想定しています。
*   クリエイティブモードなどでアイテムを出した場合、一部のカウントが進まない場合があります。
